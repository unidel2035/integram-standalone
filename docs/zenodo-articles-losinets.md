## Обзор серии

Серия из 6 статей развивает единую гидродинамическую модель квантового вакуума (QV), в которой фундаментальные взаимодействия --- электромагнетизм, гравитация, сильное взаимодействие --- описываются как проявления динамики слабовязкой жидкости. Частицы материи (нуклоны) моделируются как тороидальные вихри, фотоны --- как вихревые возмущения, а гравитация возникает из градиента давления, создаваемого поглощением энергии вакуума.

**Ключевая идея:** циркуляция = электрический заряд; вязкость = источник электромагнитного взаимодействия; константа связи `R = nu/c^2`.

## Статья 1. Formal Analogy Between Maxwell's Equations and Vortex Dynamics

**DOI:** [10.5281/zenodo.16798876](https://doi.org/10.5281/zenodo.16798876)
**Дата:** August 2025

### Abstract

Развивается формальная аналогия между динамикой вихрей в идеальной или слабовязкой жидкости и электродинамикой Максвелла. Локализованный сферический вихрь Хилла, распространяющийся с постоянной скоростью, служит прототипом. Отображение давления, скорости и завихренности на электромагнитные потенциалы и поля дает систему уравнений, идентичную уравнениям Максвелла.

### Ключевые формулы

**Волновое уравнение для вихря Хилла:**

```
psi(x, t) = f(x - ct)
d²psi/dt² = c² d²psi/dx²
```

**Отображение гидродинамических величин на электромагнитные:**

| Электромагнитная величина | Гидродинамический аналог |
|---------------------------|--------------------------|
| Scalar potential phi | phi = R * p/rho |
| Vector potential **A** | **A** = R * **u** |
| Electric field **E** | **E** = -R(nabla p/rho + d**u**/dt) |
| Magnetic induction **B** | **B** = R * (nabla x **u**) |
| Permittivity eps*eps_0 | rho (плотность среды) |
| Permeability mu*mu_0 | 1/(rho * c²) |
| Current density **j** | **j** = -rho*c²*R * d(nabla²**u**)/dt |
| Charge density sigma | sigma = -R * nabla²p |
| Charge Q | Q = integral(rho * **u** . d**S**) |

**Константа преобразования (EMHD Boltzmann constant):**

```
R = nu / c²   [s * T]
```

**Квантованная циркуляция (superfluids):**

```
integral(u . dl) = n * h / mu,   n in Z
```

**Уравнения Максвелла из гидродинамики:**

- (I) `nabla . E = c^{-2} d²phi/dt² - nabla²phi` --- закон Гаусса
- (II) `nabla . B = nabla . (nabla x u) = 0` --- закон Гаусса для магнетизма
- (III) `nabla x E = -dB/dt` --- закон Фарадея
- (IV) `c² nabla x (nabla x u) = dE/dt - nu * d(nabla²u)/dt` --- закон Ампера

### Основные результаты

1. Четыре уравнения Максвелла выводятся из уравнений Эйлера и непрерывности при отображении скорости на вектор-потенциал, давления на скалярный потенциал.
2. Вязкость nu играет роль источника диссипации и связи --- электромагнитное взаимодействие возникает только в областях с ненулевой вязкостью (заряды/токи).
3. Магнитная индукция B безразмерна в жидкостном представлении --- нормирована на R.
4. Плотность rho отождествлена с диэлектрической проницаемостью --- более плотная среда хранит больше энергии поля.

### Ограничения

- Частичная линеаризация, малые вариации плотности и давления
- Не учитывает сильную турбулентность и релятивистские поправки
- Требуется интеграция с теорией квантованных вихрей для дискретности заряда
- Возможные отклонения на высоких частотах из-за дисперсионных вязкостных эффектов

## Статья 2. Model of the Internal Structure of Nucleons

**DOI:** [10.5281/zenodo.16934346](https://doi.org/10.5281/zenodo.16934346)
**Дата:** August 2025

### Abstract

Развивается формальная гидродинамическая аналогия из статьи [1] для самосогласованного описания магнитных моментов элементарных частиц. На основе экспериментальных данных о распределении электрического заряда и магнитных моментах нуклонов построена модель их внутренней структуры как системы коаксиальных тороидальных вихрей.

### Ключевые формулы

**Заряд частицы-вихря:**

```
q = 2 * rho * V * omega
```

где rho --- плотность среды, V --- объем вихря, omega --- угловая скорость.

**Магнитный момент:**

```
mu = rho * V * (omega * r)²
```

**Система уравнений для магнитных моментов протона:**

```
mu_c + mu_m = 2.79 mu_N     (полный момент протона)
|mu_c - mu_m| = 1.91 mu_N   (момент нейтрона)
```

Решение: Set A --- `mu_c = 2.35 mu_N`, `mu_m = 0.44 mu_N`.

**Связь магнитных моментов с радиусами:**

```
mu_c / mu_m = r_m / r_c ≈ 5.2
```

Из модели: `2.35 / 0.44 ≈ 5.34` --- отличное согласие с экспериментом.

### Таблица: Сравнение параметров нуклонов

| Параметр | Эксперимент | Quark Model | Vortex Model |
|----------|-------------|-------------|--------------|
| mu_p / mu_N | 2.79 | 2.79 | 2.79 |
| mu_n / mu_N | -1.91 | -1.91 | -1.91 |
| r_m / r_c | ~5.2 | --- | 5.34 |
| r_c, fm | ~0.25 | --- | 0.25 |
| r_m, fm | ~1.3 | --- | 1.3 |

### Таблица: Параметры вихревых компонент (Set A)

| Компонента | Заряд (e) | mu/mu_N | Радиус (fm) |
|------------|-----------|---------|-------------|
| Core | +0.5 | 2.35 | 0.25 |
| Mantle | +0.5 (p), -0.5 (n) | 0.44 | 1.3 |

### Основные результаты

1. Нуклоны моделируются как два вложенных тороидальных вихря --- ядро (core, ~0.25 fm) и мантия (mantle, ~1.3 fm).
2. Модель воспроизводит экспериментальные значения магнитных моментов протона и нейтрона.
3. Отношение mu_c/mu_m = r_m/r_c --- прямое следствие модели, подтвержденное экспериментом.
4. Модель имеет педагогическую ценность --- визуализация сложных квантовых объектов через вихревое движение.

## Статья 3. Vortex Photon Model

**DOI:** [10.5281/zenodo.17063625](https://doi.org/10.5281/zenodo.17063625)
**Дата:** September 2025

### Abstract

Исследуется вихревая модель фотона как альтернативный подход к КЭД. Модель математически согласуется с формализмом Джонса для поляризации при описании поперечных компонент поля. Основное отличительное предсказание --- существование малой продольной компоненты электромагнитных волн в вакууме.

### Ключевые формулы

**Стандартные соотношения (Coulomb gauge, phi = 0):**

```
E = -dA/dt
B = nabla x A
```

**Монохроматическая волна:**

```
A(r,t) = Re[ A_0 * exp(i(k.r - omega*t)) ]
E = Re[ i*omega*A_0 * exp(i(k.r - omega*t)) ]
```

**Модельное соответствие (uniform circular motion):**

```
dA / (R_EMHD * dt) = dV/dt = V² / R = -E / R_EMHD
```

**Координаты точки вихря в лабораторной системе:**

```
r_x = R[cos(a)cos(h) - sin(a)cos(b)sin(h)]
r_y = R[sin(a)cos(h) + cos(a)cos(b)sin(h)]
r_z = R[sin(b)sin(h)]
```

где h = omega*t + phi, a и b --- углы ориентации плоскости вихря.

**Jones vector correspondence:**

```
A_x = cos(a) - i*sin(a)*cos(b)
A_y = sin(a) + i*cos(a)*cos(b)

X = exp(i*omega*t) * |A_x| * exp(i*phi_x)
Y = exp(i*omega*t) * |A_y| * exp(i*phi_y)
Z = 0   (для поперечных компонент)
```

Полное соответствие формализму Джонса для поляризации.

### Таблица: Предлагаемые эксперименты

| Эксперимент | Предсказание Standard Model | Предсказание Vortex Model |
|-------------|----------------------------|---------------------------|
| Поиск продольной компоненты | Нет детектируемого сигнала на оси пучка | Детектируемый осциллирующий сигнал на частоте излучения |
| Передача момента при поглощении фотона | Нет аномального вращательного отдачи | Измеримый вращательный отдача, зависящий от свойств вихря |

### Основные результаты

1. Для поперечных компонент модель математически эквивалентна формализму Джонса --- внутренняя согласованность.
2. Ключевое предсказание: малая продольная компонента EM-волн в вакууме (компонента r_z = R*sin(b)*sin(h)).
3. Модель фальсифицируема --- предложены два конкретных эксперимента.
4. Даже при отрицательном результате эксперименты имеют самостоятельную научную ценность (тест трансверсальности волн на новом уровне точности).

## Статья 4. Hydrodynamic Model of Gravity

**DOI:** [10.5281/zenodo.17273449](https://doi.org/10.5281/zenodo.17273449)
**Дата:** October 2025

### Abstract

Исследуется возможность описания гравитационного взаимодействия в рамках гидродинамической модели квантового вакуума. Нуклоны моделируются как тороидальные вихри, поглощающие энергию вакуума, что приводит к градиенту давления, отождествляемому с гравитацией. Модель качественно согласуется с законом всемирного тяготения и опирается на идеи индуцированной гравитации Сахарова (1967).

### Ключевые формулы

**Адиабатическое расширение:**

```
T_2/T_1 = (V_1/V_2)^{gamma-1}
Delta_T_ad = T_a * [1 - (V_1/V_2)^{gamma-1}]
```

**Мощность поглощения тепла:**

```
Q = h * S * Delta_T_ad
h = Nu * k / a,   Nu = C * Re^n,   Re = v*a / nu
```

**Баланс мощности (steady state):**

```
P_diss = eta * Q
P_diss ≈ C_d * rho * nu * v² * a
```

**Связь степени расширения со скоростью потока:**

```
V_2/V_1 ≈ 1 + v²/c_s²
```

**Самосогласованное уравнение замыкания:**

```
T_a[1 - (1/(1 + alpha*v²))^{gamma-1}] = C_d*rho*nu^{n+1}*v^{2-n}*a^{1-n} / (4*pi²*R*eta*C*k)
```

**Поле потока энергии вакуума от тела массой m:**

```
Q_total = kappa * m
S(r) = Q / (4*pi*r²)
```

**Градиент давления вакуума:**

```
dP/dr = -S(r)/c_s = -Q / (4*pi*c_s*r²)
P(r) = P_0 - Q / (4*pi*c_s*r)
```

**Сила гравитационного взаимодействия:**

```
F = -G * m_1 * m_2 / R²
G = gamma * xi_1 * xi_2 * kappa² / (4*pi*c_s)
```

где xi --- коэффициенты экранирования, kappa --- эффективность поглощения на нуклон.

### Оценки параметров модели

| Параметр | Значение |
|----------|----------|
| G | 6.67 x 10^{-11} m³/(kg*s²) |
| rho (vacuum density) | 8.85 x 10^{-12} kg/m³ |
| c_s (speed of sound in QV) | >= 1.44 x 10^{21} m/s (нижняя оценка) |
| c_s (from vacuum pressure) | ~ 1.26 x 10^{23} m/s |
| kappa | ~ 1.03 x 10^7 W/kg |
| Q per nucleon | ~ 1.71 x 10^{-20} W |
| nu (kinematic viscosity) | >= 8.61 x 10^{-11} / eta   m²/s |

### Основные результаты

1. Гравитация выводится как вторичный макроскопический эффект поглощения энергии вакуума нуклонами-вихрями.
2. Воспроизводится закон обратных квадратов F ~ m1*m2/R².
3. Гравитационная постоянная G выражена через параметры вакуума (c_s, rho, kappa).
4. Скорость звука в QV на много порядков превышает скорость света (косвенно согласуется с нелокальностью квантовых эффектов).
5. Объединение с электромагнетизмом: оба взаимодействия имеют общую гидродинамическую природу, но проявляются на разных масштабах.

## Статья 5. Modeling Strong Interaction

**DOI:** [10.5281/zenodo.17332329](https://doi.org/10.5281/zenodo.17332329)
**Дата:** October 2025

### Abstract

В рамках программы единого гидродинамического описания физических явлений проводится качественное моделирование сильного (ядерного) взаимодействия. Взаимодействие между нуклонами моделируется как результат вихрь-вихревых взаимодействий потоков в идеальной несжимаемой жидкости. Показано, что в системе двух цилиндрических вихрей на коротких расстояниях возникают силы, качественно воспроизводящие сильное взаимодействие.

### Ключевые формулы

**Euler equation (steady-state, incompressible):**

```
(u . nabla)u = -(1/rho) * nabla p
```

**Поле скорости линейного вихря (cylindrical coords):**

```
u_vortex = u_0/r * phi_1
```

**Суммарное поле (вихрь + однородный поток v):**

```
u(r, phi) = v*cos(phi) * r_1 + (u_0/r - v*sin(phi)) * phi_1
```

**Convective acceleration:**

```
[(u.nabla)u]_r = -u_0/r² * (u_0/r - v*sin(phi))
[(u.nabla)u]_phi = -v*u_0*cos(phi) / r²
```

**Плотность силы:**

```
f = -nabla p = -(rho*u_0/r²)(u_0/r - v*sin(phi)) * r_1 - rho*v*u_0*cos(phi)/r² * phi_1
```

**Предельный случай u_0 >> v (strong vortex regime):**

```
f_r ≈ -rho * u_0² / r³     (attraction, ~ 1/r³)
f_phi ≈ -rho * v * u_0 * cos(phi) / r²
```

**Hard-core repulsion (внутри ядра вихря, r <= a):**

```
f_r ≈ rho * u_0² / a² * r   (positive = repulsive, grows linearly with r)
```

### Основные результаты

1. **Притяжение** на расстояниях ~1 fm с зависимостью ~ 1/r³.
2. **Отталкивание** ("hard core") на сверхмалых расстояниях r < a --- естественно возникает при переходе от точечного вихря к вихрю с конечным ядром.
3. **Спиновая зависимость**: ось вихря = spin; параллельные вихри притягиваются сильно, антипараллельные --- взаимодействие ослабевает или переходит в отталкивание.
4. **Насыщение ядерных сил**: в плотных конфигурациях возникает экранирование и каждый вихрь взаимодействует лишь с ближайшими соседями.

### Предложенные эксперименты

1. **Спин-зависимое рассеяние нуклонов** --- поляризованные пучки нейтронов на поляризованных протонных мишенях; сравнение дифференциальных сечений для параллельных и антипараллельных спинов.
2. **Геометрические аномалии в легких ядрах** --- поиск состояний с аномально низкой связью, соответствующих "неэффективным" геометрическим конфигурациям вихрей (например, ^{10}He, нейтронные гало).
3. **Гидродинамические корреляции в релятивистских столкновениях тяжелых ионов** --- поиск аномально сильных коллективных потоков (v1, v2) на RHIC/LHC, связанных с вихревой структурой сталкивающихся ионов.

## Статья 6. A Unified Hydrodynamic Model of the Quantum Vacuum

**DOI:** [10.5281/zenodo.17422925](https://doi.org/10.5281/zenodo.17422925)
**Дата:** October 2025

### Abstract

Итоговая работа серии. Суммирует результаты статей [1--5] и строит единую систему, в которой определены параметры гидродинамической среды, моделирующей квантовый вакуум. Модель позволяет согласованное феноменологическое описание, связывающее ядерные взаимодействия, электромагнетизм, гравитацию и некоторые квантовые эффекты в единой гидродинамической рамке.

### Критерии оценки модели

1. **Internal consistency** --- логическая когерентность между постулатами и выводами
2. **External consistency** --- воспроизведение экспериментальных фактов
3. **Heuristic power** --- способность порождать новые фальсифицируемые гипотезы
4. **Unifying capacity** --- интеграция разнородных явлений в единую систему

### Иерархия единой картины

```
Foundation:     Гидродинамические эквиваленты EM-величин
    |
Matter:         Нуклоны как стабильные вихревые системы
    |
Interactions:   1. EM --- прямое взаимодействие полей скорости и давления
                2. Strong --- вихревая связь и геометрическое насыщение
                3. Gravity --- градиенты давления от поглощения энергии
    |
Quantum:        Фотоны как вихревые возмущения с квантованным угловым моментом
```

### Определение плотности квантового вакуума

Из закона Гаусса и закона Кулона:

```
eps_0 = b * rho
```

При b = 1 (SI units):

```
eps_0 = rho = 8.854 x 10^{-12} F/m = 8.854 x 10^{-12} kg/m³
```

**Напряженность поля на радиусе протона:**

```
E_eff = Q_p / (4*pi*eps_0*r_p²) ≈ 2.1 x 10^{21} V/m
```

--- совпадает с классическим кулоновским полем, подтверждая внутреннюю согласованность.

### Полная таблица соответствий EM <-> Hydrodynamics

```
R_e = nu / c²

phi = R_e * p / rho
A  = R_e * u
E  = -R_e * (nabla p / rho + du/dt)
B  = R_e * nabla x u

eps*eps_0 = rho
mu*mu_0  = 1 / (rho*c²)

j     = -rho*c²*R_e * d(nabla²u)/dt
sigma = -R_e * nabla²p

Q = integral(rho*u . dS) = integral(rho*omega . dV)
I = integral(d(rho*u)/dt . dS)
M = integral(rho*omega² . dV)
```

### Оценки параметров QV

| Параметр | Обозначение | Оценка |
|----------|-------------|--------|
| Плотность QV | rho | 8.85 x 10^{-12} kg/m³ (free space) |
| Плотность QV в нуклоне | rho_nucleon | ~6.7 x 10^{17} kg/m³ |
| Скорость потока у ядра | u | ~c = 3 x 10^8 m/s |
| Константа поглощения | kappa | ~10^7 W/kg |
| Conversion constant | R_e = nu/c² | ~10^{-27}/eta |
| Давление QV | p_QV | >= 10^{35} Pa |
| Скорость звука в QV | c_s | >= 10^{21} m/s |

### Основные результаты серии

1. **Электромагнетизм** --- полный набор уравнений Максвелла выводится из гидродинамики вихрей.
2. **Структура нуклонов** --- два вложенных тороидальных вихря воспроизводят магнитные моменты и радиусы протона и нейтрона.
3. **Фотоны** --- вихревая модель воспроизводит формализм Джонса и предсказывает продольную компоненту.

5. **Сильное взаимодействие** --- притяжение (~1/r³), hard-core repulsion и спиновая зависимость из вихревой динамики.
6. **Унификация** --- все взаимодействия описаны через единую среду с согласованными параметрами.

## Программа экспериментальной верификации (сводка)

- Квантованные вихри в BEC и сверхтекучем гелии
- Поиск отклонений от классической электродинамики на высоких частотах

### Структура нуклонов (статья 2)
- Измерение распределения намагниченности внутри нуклона
- Изучение возбужденных состояний (резонансов) --- переходы между конфигурациями вихрей
- Кинематические особенности в глубоко-неупругом рассеянии

### Фотоны (статья 3)
- Прямое детектирование продольной компоненты EM-поля вдоль коллимированного пучка
- Измерение вращательного отдачи при поглощении одиночного фотона
