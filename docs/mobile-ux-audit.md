# Mobile UX/UI Audit — VentureOS (390×844, iPhone 14 Pro)

**Дата:** 2026-03-09
**Viewport:** 390×844px
**Скриншоты:** `/mobile-audit/`

---

## Общая оценка: 6.5 / 10

Платформа функционально работает на мобильном — контент доступен, навигация возможна. Но ряд экранов спроектирован для десктопа и требует адаптации для комфортного использования на мобильных устройствах.

---

## 1. Аудит по маршрутам

### `/login` — Вход — 8/10
**Хорошо:**
- Форма центрирована, поля достаточного размера
- Кнопка «Войти» крупная, удобная для тапа

**Проблемы:**
- [ ] Много пустого пространства сверху — форма смещена в нижнюю часть экрана

### `/fst` — Хаб (Landing) — 9/10
**Хорошо:**
- Отлично адаптирован: карточки в одну колонку, текст читаемый

- Сравнительная секция «Традиционный фонд vs ФСТ НТИ» хорошо работает в стеке

**Проблемы:**
- [ ] Мелкие статистические карточки (48ч, 6, 3, 100%) — текст мелкий, трудно читается

### `/fst-committee` — AI-инвесткомитет — 7/10

- Бейджи TRL/MRL/Суверенность компактные и читаемые

- [ ] **Настройки симуляции** (скорость, режим) занимают слишком много вертикального пространства — нужен аккордеон или bottom sheet
- [ ] **Две колонки** (проекты + настройки) не помещаются — нужен tab-switch или swipe между проектами и настройками

## 2. Общие проблемы (Cross-cutting)

### Sidebar / Навигация
- [ ] **Sidebar открывается в icon-only режиме** — иконки без подписей, непонятно что за маршрут
- [ ] **Нет backdrop/overlay** при открытом sidebar — контент виден позади, визуальный шум
- [ ] **Touch targets**: иконки sidebar ~36px, нужно минимум 44x44px (Apple HIG)

### Toolbar (FstPageLayout)
- [ ] **Главная боль** — toolbar на ВСЕХ страницах переполняется на 390px
- [ ] Кнопки действий (Сохранить, Обновить, Term Sheet) обрезаются или выходят за экран
- [ ] **Решение**: на мобилке toolbar должен переходить в «overflow menu» (kebab) или sticky bottom action bar

### Master-Detail Pattern
- [ ] Страницы Portfolio, Committee, Deal используют 2-3 колонки desktop layout
- [ ] На мобилке нужен **list -> detail** переход (навигация вперёд-назад), а не параллельные панели

### Типографика
- [ ] Некоторые заголовки слишком длинные и обрезаются
- [ ] Метки на графиках нечитаемы на 390px

### Графики (Chart.js)
- [ ] Все графики слишком маленькие — оси и значения не читаются
- [ ] Нужен maintainAspectRatio: false + увеличенная высота на мобилке

## 3. План улучшений (приоритезированный)

### P0 — Критические (ломает UX)

1. **Toolbar overflow -> responsive action bar**
   - Файлы: `src/components/fst-shared/FstPageLayout.vue`, все Fst*.vue
   - На `< 768px`: кнопки действий -> bottom sticky bar или overflow menu
   - Оценка: 3-4 часа

2. **Master-detail на мобилке для Portfolio / Committee**
   - Файлы: `FstPortfolio.vue`, `FstCommittee.vue`
   - Список занимает 100% -> тап -> детали на новом «экране» (v-if toggle)
   - Оценка: 4-5 часов

3. **Sidebar mobile overlay**
   - Файл: `src/layout/AppSidebar.vue`, `_responsive.scss`
   - Открытый sidebar: показать labels + добавить backdrop overlay
   - Touch targets -> 44x44px minimum
   - Оценка: 2-3 часа

### P1 — Важные (затрудняет использование)

4. **Kanban горизонтальный свайп**
   - Файл: `FstExecution.vue`
   - CSS overflow-x: auto + snap scroll на колонках
   - Оценка: 1-2 часа

5. **Финансовые таблицы — horizontal scroll**
   - Файл: `FstDeal.vue`
   - Обёртка overflow-x: auto + scroll indicator
   - Оценка: 1 час

6. **Графики — увеличенная высота на мобилке**
   - Файлы: `FstDigitalTwin.vue`, `FstFundTwin.vue`
   - Media query: min-height: 250px на мобилке (вместо ~150px)
   - Оценка: 1 час

7. **Stepper на Apply — горизонтальный скролл**
   - Файл: `FstApply.vue`
   - overflow-x: auto или сокращённые лейблы на мобилке
   - Оценка: 30 мин

### P2 — Косметические (улучшает ощущения)

8. **Login — вертикальное центрирование**
   - Файл: компонент логина
   - align-items: center; min-height: 100vh
   - Оценка: 15 мин

9. **Матрица здоровья портфеля — увеличенные ячейки**
   - Файл: `FstFundTwin.vue`
   - На мобилке: grid -> вертикальный список
   - Оценка: 1 час

10. **Настройки ИК — collapsible accordion**
    - Файл: `FstCommittee.vue`
    - Скорость/Режим/Модели -> PrimeVue Accordion, по умолчанию свёрнуты
    - Оценка: 1-2 часа

## 4. CSS-стратегия

```scss
// Breakpoints
$mobile: 576px;
$tablet: 768px;

// В _responsive.scss добавить:
@media (max-width: #{$tablet}) {
  // 1. Toolbar -> stack вертикально или overflow menu
  .fst-page-toolbar .p-toolbar-end {
    flex-wrap: wrap;
    gap: 0.5rem;
  }

  // 2. Two-panel layouts -> single column
  .fst-split-layout {
    flex-direction: column;
    .fst-panel-left, .fst-panel-right {
      width: 100% !important;
      max-width: 100% !important;
    }
  }

  // 3. Charts bigger
  .chart-container canvas {
    min-height: 220px !important;
  }

  // 4. Touch targets
  .layout-sidebar .layout-menu li {
    min-height: 44px;
    padding: 0.75rem;
  }
}
```
