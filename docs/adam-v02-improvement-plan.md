# Адам v0.2 — План улучшений

## Диагностика v0.1 (20 вопросов)
- **9/20 отлично** — онтология дара, формула R, surplus, кеносис, эпектасис
- **6/20 средне** — поверхностные ответы, нет деталей
- **5/20 галлюцинации** — Шкляев, Лосинец, вихрь Хилла, сильное взаимодействие

## Корневые проблемы

### 1. Шкляев не закрепился (9 примеров — мало)
**Симптом:** "Иван Федорович Шкляев", "монах и комментатор" — галлюцинации
**Причина:** 9 примеров недостаточно чтобы перебить pre-training bias Qwen
**Решение:** Добавить 25-30 примеров:
- "Кто такой о.Сергий Шкляев?" → биография
- "Что Шкляев говорит о благодати?" → детектор истины
- "Что Шкляев говорит о смирении?" → МИР ≠ НЕ-МОЩЬ (этимология)
- "Что Шкляев говорит о помыслах?" → бесовский троллинг, belt of truth
- Прямые цитаты из 87 сообщений в Чудиках

### 2. Лосинец не закрепился (12 примеров — мало для имени)
**Симптом:** "Лосинец — земледельческий термин" — галлюцинация
**Причина:** Модель знает физику (формулу R, гравитация+кеносис), но не связывает с именем "Лосинец"
**Решение:** Добавить 15-20 примеров:
- "Кто такой Лосинец Дмитрий?" → физик, 6 статей Zenodo, канал Осенило
- "Что открыл Лосинец?" → формальная аналогия Maxwell = вихри
- "Что такое вихрь Хилла по Лосинцу?" → сферический вихрь, модель фотона
- "Как Лосинец объясняет сильное взаимодействие?" → fr ≈ ρu₀²/a²·r (конфайнмент)
- "Какие параметры эфира по Лосинцу?" → давление ≥ 10³⁵ Па, cs ≈ 1.26×10²³ м/с

### 3. Формат дара не закрепился
**Симптом:** Нет структуры [ДАР]/[СЛОЙ]/[КЕНОСИС]/[ТЕЛОС]
**Причина:** 53 примера дара есть, но модель генерирует свободный текст вместо формата
**Решение:** Добавить 10 примеров с явным требованием формата:
- "Предложи дар в формате [ДАР]/[КЕНОСИС]/[ТЕЛОС]"
- Разнообразить телосы: σωτηρία, χάρις, ἀλήθεια, εἰρήνη

### 4. Физика эфиродинамики — детали
**Симптом:** "вихрь Хилла = теория относительности" — галлюцинация
**Причина:** Модель знает абстракции, но не конкретику
**Решение:** Добавить 10 примеров:
- Конкретные формулы (B ~ ∇×u, E ~ −∇p/ρ − ∂ₜu)
- Таблица соответствий EM ↔ гидродинамика
- Параметры нуклонов (μp/μN = 2.79, rm/rc ≈ 5.34)
- Вихрь Хилла = сферическое вихревое кольцо (НЕ теория относительности)

### 5. Троичная логика — новая тема
**Симптом:** Не знает связь {-1, 0, +1} с онтологией дара
**Причина:** Не было в датасете
**Решение:** Добавить 5-10 примеров:
- "Что такое троичная логика?" → {-1, 0, +1} = {кеносис, апофатика, surplus}
- "Как троичная логика связана с Троицей?"
- "Зачем FPGA для троичных вычислений?"
