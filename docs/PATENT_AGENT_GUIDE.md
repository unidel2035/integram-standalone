## Инструкция для агента: как подавать следующие патенты

```
1. Получить описание изобретения от пользователя
2. Запустить поиск prior art:
   - WebSearch: site:patents.google.com "ключевые слова"
   - WebSearch: arxiv "технология" patent
   - WebSearch: USPTO "тема" application
3. Написать заявку по шаблону PATENT_APPLICATION.md
4. Сохранить в docs/patent_{название}_{дата}.md
5. Рассчитать пошлины
6. Сообщить пользователю: что готово, что нужно сделать вручную
```
