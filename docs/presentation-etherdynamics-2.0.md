### 2. Аксиоматика эфиродинамики
- **Аксиома** — очевидность, ясная и бесспорная истина, не требующая доказательств
- **Постулат** — недоказуемое положение, признаваемое истинным по необходимости
- Три аксиомы:
  1. Природа объективно существует
  2. Природа познаваема через взаимодействие
  3. Механика Ньютона справедлива
- Эфиродинамика — попытка построить полную физическую картину мира, исходя из минимальной и ясной аксиоматики, где каждое следующее утверждение является логически неизбежным следствием из предыдущих

| Свойство | Аксиома | Постулат |
|----------|---------|----------|
| Логическая необходимость | ✓ | ❌ |
| Самоочевидность | ✓ | ❌ |

### 3. Принцип фундаментального постоянства
Сложность систем формируется постепенно при постоянстве условий и избытке энергии.

| Критерий | Антропный принцип | Фундаментального постоянства |
|----------|------------------|------------------------------|
| Ключевое требование | Наблюдатель связан с константами | Физические законы стабильны |
| Механизм усложнения | "Тонкая настройка" | Через сохранение адаптации |
| Роль наблюдателя | Ключевая | Случайная |
| Мультивселенные | Необходимы | Не нужны |

### 4–5. Эфир и квантовый вакуум (2 слайда)
- Эфир по Демокриту — апейрон, неопределённая материя
- Вещество — структурированный эфир
- Квантовый вакуум — конкретный слой эфира, который исследуют учёные
- "Первые принципы" — ошибочная методология. Решение за феноменологией
- Квантовый вакуум можно моделировать гидродинамическими моделями (почти мейнстримная методология)

**Модель vs Реальность:**
| Модель | Реальность |
|--------|-----------|
| Сплошная среда | Количество частиц в характерном объёме достаточно велико |
| Несжимаемая среда | Изменение объёма при изменении давления достаточно мало |
| Идеальная (невязкая) среда | Отношение инерционных сил к вязким достаточно велико |
| Истинная случайность | Нерепрезентативное число частиц в характерном объёме |

### 6. Инерция — врождённое свойство материи
- Любое взаимодействие изначально требует инерции
- Все взаимодействия происходят только при обмене импульсом/энергией — инерционным взаимодействием
- Если у эфира есть инерция, она автоматически есть у любой материи, состоящей из эфира
- Присоединённая масса ≈ массе половины вытесненного объёма
- Плотность эфира низкая: низкая динамическая вязкость, высокая скорость звука, давление ≥ 10^35 Па

### 7–10. Вязкая электродинамика (4 слайда)
**Ссылка:** Losinets, D. S. (2025). *Formal Analogy Between Maxwell's Equations and Vortex Dynamics in Weakly Viscous Media.* Zenodo. https://doi.org/10.5281/zenodo.16798876

**Ключевые формулы:**
- Волновое уравнение: `ψ(x,t) = f(x − ct)`, `∂ₜₜψ = c²∂ₓₓψ`
- Квантование циркуляции: `∮u·dl = n·h/μ, n ∈ ℤ`
- Уравнение Навье-Стокса: `(u·∇)u = −∇p/ρ − ∂ₜu`
- Тождество Лэмба: `½∇u² = u × (∇ × u) + (u·∇)u`
- **Сила Лоренца через гидродинамику:** `f = ρ[u × (∇ × u) − ∇p/ρ − ∂ₜu]` → `f = σ(u × B + E)`
- **Соответствия:** `B ~ ∇ × u`, `E ~ −∇p/ρ − ∂ₜu`
- **Потенциалы:** `φ = p/ρ`, `A = u`
- Дивергенция: `∇·B = ∇·(∇ × u) = 0`
- Ротор: `∇ × E = −∇ × ∇φ − ∂ₜ(∇ × u) = −∂ₜB`
- Плотность тока: `j = −ν∂ₜ∇²u`
- Плотность заряда: `σ = −νc⁻²∇²p`

**Таблица соответствий (слайд 9):**

| Electromagnetic quantity | Hydrodynamic analogue | SI unit | Unit in model |
|---|---|---|---|
| Scalar potential φ | φ = Rₑ p/ρ | V | m²s⁻¹ |
| Vector potential A | A = Rₑ u | V·s·m⁻¹ | m |
| Electric field E | E = −Rₑ(∇p/ρ + ∂ₜu) | V·m⁻¹ | m·s⁻¹ |
| Magnetic induction B | B = Rₑ ∇ × u | T | dimensionless |
| Dielectric permittivity εε₀ | εε₀ = ρ | F·m⁻¹ | kg·m⁻³ |
| Magnetic constant μμ₀ | μμ₀ = 1/(ρc²) | H·m⁻¹ | m²·kg⁻¹ |
| Current density j | j = −ρc²Rₑ∂/∂t ∇²u | A·m⁻² | kg·m⁻²·s⁻¹ |
| Charge density σ | σ = −Rₑ ∇²p | C·m⁻³ | kg·m⁻³·s⁻¹ |

**Визуализация (слайд 10):** обтекание тела с силой Лоренца, фото вихрей в лаборатории.

### 11–12. Поляризация фотонов (2 слайда)
**Ссылка:** Losinets, D. S. (2025). *Vortex Photon Model: Program for Experimental Verification.* Zenodo. https://doi.org/10.5281/zenodo.17063625

**Формулы:**
- `E = −∂A/∂t`, `B = ∇ × A`
- `A(r,t) = Re{A₀ e^(i(k·r−ωt))}`
- Матрицы поворота Rₓ(−b), Rz(−a) для преобразования координат
- `E_global = Rz(−a)·Rₓ(−b)·E_loc`
- Амплитуды: `Eₓ = |Aₓ| = √(cos(a) − i·sin(a)·cos(b))²`
- Результирующие: `X = e^(iωt)·Eₓ·e^(iφₓ)`, `Y = e^(iωt)·Eᵧ·e^(iφᵧ)`, `Z = 0`

### 13–14. Модель фотонов (2 слайда)
Фотон как вихревое кольцо (вихрь Хилла) в эфире.

**Сравнение КМ vs Эфиродинамика:**

| Явление | Стандартная интерпретация | Эфиродинамическая интерпретация |
|---------|--------------------------|--------------------------------|
| Что такое фотон? | Безмассовая частица, квант поля | Вихревое кольцо (вз. Хилла), возмущение физической среды (эфира) |
| Постоянная Планка (ℏ) | Квант действия из абстрактного квантования | Момент импульса кольца Хилла. Следствие квантования из характеристик среды |
| Формула E = hf | Постулат. Фундаментальное соотношение | Следствие: сохранение момента импульса в классической механике |
| Почему скорость = c | Постулат. Свойство безмассовых состояний | Самосогласованная структура: скорость = скорость звука в эфире = c (по определению среды) |
| Поляризация | Квантовая суперпозиция ортогональных состояний | Ориентация вихревого импульса вокруг оси распространения |
| Красное смещение | Расширение Вселенной или релятивистский эффект Доплера | "Старение кванта": диссипация вихря → уменьшение энергии при сохранении импульса |

### 16–17. Параметры нуклонов (2 слайда)
**Ссылка:** Losinets, D. S. (2025). *Model of the Internal Structure of Nucleons Based on a Vortex Analogy: A Self-Consistent Description of Magnetic Moments.* Zenodo. https://doi.org/10.5281/zenodo.16934346

**Ключевые формулы:**
- Заряд: `q = 2ρVω`
- Магнитный момент: `μ = ρV(ωr)²`
- Отношение: `μc/μm = (ωc·rc²)/(ωm·rm²) = (Vm/V)·rc²/rm² ≈ 5.34`
- Система: `{μc + μm = 2.79μN, |μc − μm| = 1.91μN}`

**Сравнение моделей:**

| Parameter | Experiment | Quark Model | Vortex Model |
|-----------|-----------|-------------|-------------|
| μp/μN | 2.79 | 2.79 | 2.79 |
| μn/μN | −1.91 | −1.91 | −1.91 |
| rm/rc | ~5.2 | — | 5.34 |
| rc, fm | ~0.25 | — | 0.25 |
| rm, fm | ~1.3 | — | 1.3 |

Визуализация: вихревая структура нуклона + аналогия с торнадо.

### 18–19. Ядерные взаимодействия (2 слайда)
**Ссылка:** Losinets, D. S. (2025). *Modeling Strong Interaction within a Hydrodynamic Model of Quantum Vacuum: A Qualitative Study.* Zenodo. https://doi.org/10.5281/zenodo.17332329

**Формулы силы взаимодействия вихрей:**
- Скорость: `u(r,φ) = v·cosφ·r₁ + (u₀/r − v·sinφ)·φ₁`
- Ускорение: `(u·∇)u = −u₀/r²·(u₀/r − v·sinφ)·r₁ − v·u₀·cosφ/r²·φ₁`
- Сила: `f = −ρ·u₀/r²·(u₀/r − v·sinφ)·r₁ − ρ·v·u₀·cosφ/r²·φ₁`
- **На больших расстояниях:** `fr ≈ −ρ·u₀²/r³` (аналог кулоновского)
- **На малых расстояниях:** `fr ≈ ρ·u₀²/a²·r` (линейный конфайнмент, аналог сильного взаимодействия)

Визуализация: два вихря Хилла (B, H) — притяжение/отталкивание.

### 20–21. Гравитация в единой модели (2 слайда)
**Ссылка:** Losinets, D. S. (2025). *Hydrodynamic Model of Gravity as Manifestation of Quantum Vacuum Energy Exchange.* Zenodo. https://doi.org/10.5281/zenodo.17273449

**Ключевые формулы:**
- Адиабатическое расширение: `ΔTad = Ta − Tv = Ta[1 − (V₁/V₂)^(γ−1)]`
- Теплообмен: `Q = hSΔTad`
- Диссипация: `Pdiss ≈ Cd·ρ·ν·v²·a`
- Градиент давления: `∂P/∂r = ρ·v₀²/r`
- Полный теплообмен: `Qtotal = κm`, `S(r) = Q/(4πr²)`
- Давление: `dP/dr = −S(r)/cs`, `P(r) = P₀ − Q/(4πcs·r)`
- **Эффективный теплообмен:** `Qeff = ξκm`
- **Закон Ньютона:** `F = −γ(ξ₂κm₂)∇P₁` → `F = −G·m₁m₂/R²·ê_R`
- **Гравитационная постоянная:** `G = γξ₁ξ₂κ²/(4πcs)`

Диаграмма гравитационного механизма: уплотнение → разрежение → диссипация → поглощение тепла (циклический процесс).

### 22. Параметры эфира
**Ссылка:** Losinets, D. S. (2025). *A Unified Hydrodynamic Model of the Quantum Vacuum as the Basis for Fundamental Interactions.* Zenodo. https://doi.org/10.5281/zenodo.17422925

**Численные параметры:**
- `ε₀ = bρ` (диэлектрическая проницаемость)
- `G = γξ₁ξ₂κ²/(4πcs)` (гравитационная постоянная)
- `ν ≈ 8.6 × 10⁻¹¹/η`, где `0 < η ≤ 1` (кинематическая вязкость)
- `κ ~ 10⁷ W/kg` (удельный теплообмен)
- `Rₑ = ν/c² ≈ 10⁻²⁷/η` (электродинамический масштаб)
- `p = ρcs²/γ ≥ 10³⁵ Па` (давление эфира)
- `b = 1` (параметр связи)
- `cs = √(γP/ρ) ≈ √(1.4×10³⁵/8.85×10⁻¹²) ≈ 1.26 × 10²³ м/с` (скорость звука в эфире)

**Сводная таблица соответствий:**
- `Rₑ = ν/c²`, `φ = Rₑ·p/ρ`, `A = Rₑ·u`
- `E = −Rₑ(∇p/ρ + ∂u/∂t)`, `B = Rₑ·∇ × u`
- `εε₀ = ρ`, `μμ₀ = 1/(ρc²)`
- `j = −ρc²Rₑ·∂/∂t·∇²u`, `σ = −Rₑ·∇²p`
- `Q = ∮(ρu)dS = ∫(ρω)dV`, `I = ∫∂/∂t(ρu)·dS`, `M = ∫(ρω²)dV`

### 23–24. Структура ядер атомов (2 слайда)
3D-модели ядер: H1, He4, Li7, Be9, B11, C12.
- Вихревые кольца как протоны (красные) и нейтроны (синие)
- Геометрические конфигурации: тетраэдры, октаэдры
- Применение к молекулярной химии: метан CH4 (sp³-гибридизация), бензол C6H6, молекула воды

### 25. Эфирный ветер через камеры наблюдения
Предлагаемый эксперимент: обнаружение эфирного ветра через субпиксельный сдвиг (2px) на камерах наблюдения. Схема: камера → эфирный ветер → вихревая структура частиц смещается.

### 26. Экспериментальная проверка
Предлагаемые эксперименты:
1. Исследование сил, действующих на вихри Хилла
2. Исследование нелинейных эффектов электродинамики
3. Изменение скорости света вблизи массивных тел или в сильных полях
4. Исследование распределения магнитного момента и заряда частиц
5. Поиск ротационных эффектов при ядерных преобразованиях
6. Исследование возбуждённых состояний атомов
7. Поиск продольной компоненты поля у фотонных излучений
8. Поиск механического углового момента у поляризованного света
9. Зависимость рассеивания частиц от направления спина
10. Геометрические аномалии лёгких ядер атомов
11. Поиск эффектов, связанных с поглощением энергии частицами
12. Отклонение от гравитационного закона в сильных полях
13. Зависимость гравитации от квантовых флуктуаций
14. Отклонение от гравитационного закона на сверхкоротких дистанциях
