| 1156 | Название компании, ИНН, ОГРН | SHORT (1042) |

### 2. Решения ИК (typeId: 1160)

Протокол каждого заседания ИК с результатами дебатов AI-агентов.

**Сохраняется полный JSON протокола:**
- Аргументы всех 6 агентов (OPENING, CHALLENGE, COUNTER, SUMMARY)
- Голоса каждого агента с баллами и уверенностью
- Итоговое решение, рекомендация, условия одобрения
- Параметры политики ФСТ на момент сессии

| Req ID | Алиас | Тип | Описание |
|--------|-------|-----|----------|
| 1161 | Итоговый скор %, Голосов ПРОТИВ | NUMBER (144) | Агрегированный балл 0-100, количество голосов ПРОТИВ |
| 1162 | Протокол дебатов (JSON), Условия одобрения | HTML (1018) | Полный JSON сессии: агенты, аргументы, голоса, решение |
| 1163 | Дата заседания | DATETIME (123) | Timestamp сессии |
| 1186 | Проект | REF → Проекты (1155) | Связь с рассмотренным проектом |
| 1188 | Решение ИК | REF → Статусы решений (1090) | APPROVE/DEFER/REJECT |

## Пример: создать проект через JS

```javascript
// auth
const { token, _xsrf } = await fetch('https://ai2o.ru/fst/auth?JSON_KV', {
  method: 'POST', body: 'login=d&pwd=d'
}).then(r => r.json())

// создать проект (typeId=1155)
const body = new URLSearchParams({
  't1155': 'АвиаЛогик',       // название (val)
  't1156': 'ООО АвиаЛогик',   // Название компании
  't1157': '5',                // TRL
  '_xsrf': _xsrf
})
await fetch('https://ai2o.ru/fst/_m_new/1155?JSON_KV', {
  method: 'POST',
  headers: { 'X-Authorization': token },
  body
})
```
