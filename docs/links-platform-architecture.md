# LinksPlatform в ФСТ НТИ VentureOS

> Архитектура графа связей — от онтологии БПЛА до решений инвесткомитета

## Концепция

Основана на [LinksPlatform (konard)](https://github.com/konard/LinksPlatform):
- **Всё — дублет** `(source → target)`
- **Связи — первоклассные объекты**: сами могут быть source/target (гипер-граф)
- Нет жёстких схем — одна универсальная таблица

## Хранение

**Integram `fst` база, таблица "Связь" (typeId: 4049)**

| Реквизит | ID | Тип | Описание |
|----------|----|-----|---------|
| ИдИсточника | 4051 | NUMBER | ID источника |
| ТипИсточника | 4053 | SHORT | 'company' \| 'session' \| 'argument' \| 'concept' \| 'link' |
| ИдЦели | 4055 | NUMBER | ID цели |
| ТипЦели | 4057 | SHORT | аналогично |
| ТипСвязи | 4059 | SHORT | см. LINK_TYPES |
| Вес | 4061 | NUMBER | 0–100 (уверенность/сила) |
| Мета | 4063 | LONG | JSON: { conceptName, companyName, verdict, ... } |

## Типы сущностей

```
company   — портфельная компания (id из PORTFOLIO в FstPortfolio.vue)
concept   — концепт онтологии БПЛА (kval, typeId 1673250)
session   — сессия инвесткомитета (session.id из FstCommitteeEngine)
argument  — аргумент дебатов (arg.id из session.arguments)
link      — другая связь (гипер-граф)
```

## Типы связей (LINK_TYPES)

| Ключ | Значение | Иконка |
|------|---------|--------|
| `uses` | Использует технологию | 🔧 |
| `produces` | Производит продукт | 📦 |
| `part-of` | Входит в состав | 🗂️ |
| `is-a` | Является разновидностью | 🏷️ |
| `applies-to` | Применяется в области | 🗺️ |
| `competes` | Конкурирует с | ↔️ |
| `invests-in` | Инвестирует в | 📈 |
| `related` | Общая связь | 🔗 |

## Интеграция с инвесткомитетом

### Фаза LOADING
1. **`detectPortfolioOverlap(subFund)`** — находит компании портфеля с пересекающимися концептами
2. **`tagSessionWithConcepts(sessionId, subFund)`** — создаёт `session → concept` связи по субфонду
3. Если найдены пересечения — UI показывает алерт с кнопкой "Граф →"

### Фаза CONCLUDED
4. **`recordSessionDecision(sessionId, companyId, verdict, score)`** — фиксирует `session → company` (linkType: `invests-in`)
5. **`linkArgumentToConcept(argId, conceptId)`** — связывает аргументы дебатов с концептами (гипер-граф)

### Маппинг субфондов → концепты онтологии
```
БАС  → БПЛА / Дрон (1673296), Промышленный БПЛА (1673319), Гражданский БПЛА (1673303)
МЭ   → Компонент (1697337), Сенсоры (1692129), Навигация GNSS/RTK (1692121)
РОБО → С/х БПЛА (1673326), Сельское хозяйство (1692160), Мониторинг (1692184)
НТИ  → ИИ и машинное зрение (1692145), Автопилот (1692113), Технологии БПЛА (1692106)
```

## Гипер-граф (LinksPlatform принцип)

Связь может ссылаться на другую связь:
```
argument:arg_1234 ──references──► concept:1692145 (ИИ и машинное зрение)
link:4066 ──related──► link:4186        ← мета-связь между двумя связями
```

Это позволяет задавать запросы типа:
- "Какие аргументы ссылались на ИИ-концепты?"
- "Какие компании связаны через общий концепт-посредник?"

## API сервиса

```javascript
import {
  createLink,          // создать связь
  linkLinks,           // гипер-связь между связями
  getLinks,            // все связи сущности
  getAllLinks,          // все связи (для графа)
  getConceptsForCompany,   // концепты компании
  getCompaniesForConcept,  // компании по концепту
  detectPortfolioOverlap,  // пересечения проекта с портфелем
  tagSessionWithConcepts,  // авто-тег сессии ИК
  recordSessionDecision,   // фиксация решения ИК
  linkArgumentToConcept,   // аргумент → концепт (гипер-граф)
  getFullGraph,            // весь граф для визуализации
  deleteLink,
  LINK_TYPES,
} from '@/services/fstLinksService'
```
